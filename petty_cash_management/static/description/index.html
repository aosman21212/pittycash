Petty Cash Management

A complete petty cash solution for Odoo 19 — manage employee cash funds, track requests through a structured approval workflow, and maintain full accounting integration with automatic journal entries.

Key Features

🏦

Employee Fund Setup

Automatically create a dedicated cash account and journal for each employee's petty cash fund with a single click — no manual accounting configuration needed.

📋

Request Workflow

Structured 4-step approval process: Draft → Submitted → Approved → Paid. Role-based access ensures only managers can approve or reject requests.

📊

Transaction Ledger

Real-time running balance for every fund. Each transaction shows debit, credit, and cumulative balance with automatic updates when requests are approved.

💰

Full Accounting Integration

Automatic journal entries on approval — debits the expense account and credits the petty cash account. Fully integrated with Odoo's double-entry accounting engine.

🖥️

OWL Dashboard

Real-time KPI dashboard built with OWL showing total funds, balance, pending approvals, monthly spend, request status breakdown, and recent activity tables.

📄

PDF Reports

Professional printable request reports with company header, full request details, approval information, and three signature lines (Requested / Approved / Paid).

👥

HR Employee Integration

Petty cash funds appear directly on the employee form with a smart button showing fund count and a dedicated "Petty Cash" tab for fund management.

🌐

Bilingual Support

Complete Arabic and English translations for all field labels, button names, status labels, menu items, and dashboard strings — ready for Middle East deployments.
